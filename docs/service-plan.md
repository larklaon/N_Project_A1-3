# 서비스 기획서 — 실기 한 걸음

## 목적과 사용자

정보처리산업기사 실기를 준비하며 긴 해설을 읽기보다 한 단계씩 답하며 배우고 싶은 학습자가 대상입니다. 작은 질문으로 시작 부담을 줄이고, 단답 확인과 AI 설명을 연결하고, 헷갈린 질문을 다음 공부로 이어가게 합니다.

## 페이지 구성

| 메뉴 | 제공 가치 |
| --- | --- |
| 학습 홈 | 실제 학습 진도, 다음 질문, 9개 학습 영역 선택 |
| 한 질문씩 배우기 | 89개 수업의 단계별 질문·단답 확인·힌트·AI 대화 |
| 단답 연습 | 창작 연결 문제에서 최대 12개를 무작위 출제하고 즉시 확인 |
| 다시 볼 질문 | 사용자가 담거나 연습에서 놓친 질문 복습·내려받기 |
| 학습실 소개 | 자료 범위·채점 의미·데이터 전달·저장·기록 초기화 안내 |

좌측 메뉴를 통해 URL 해시로 이동합니다. 모바일에서는 상단 메뉴가 여러 줄로 바뀌고 학습/대화 패널은 한 열로 표시됩니다.

## 핵심 기능

창작 문항 391개를 9개 영역의 89개 수업으로 구성합니다. 마이크로 질문부터 연결 문제로 이어집니다. 탐색·힌트·정답 공개는 정답 기록으로 집계하지 않고, 등록 정답 확인 또는 AI의 전체 답 확인을 별도로 처리합니다. 단답 연습의 점수는 그 연습의 실제 제출 결과만 집계합니다. 등록 답 비교는 공식 채점이나 자유 서술 의미 평가가 아닙니다.

## AI 입력·출력·실패 기준

- 기본 제공자: Gemini. 추가 제공자: OpenAI. API 호출은 Python 서버에서 수행합니다.
- 입력: 서버에 존재하는 창작 문항 ID, 과정 ID, 선택 제공자, 현재 질문의 최근 12개 대화. 마지막 메시지는 비어 있지 않은 2,000자 이하 사용자 메시지입니다.
- 가치: 문장형 답의 학습 피드백, 힌트, 오답 원인, 쉬운 예시, 자세한 해설, 학습 방법 등 다양한 요청에 대응합니다.
- 출력: 한국어 설명 `text`와 `correct/retry/explain` 판정. 전체 질문에 올바르게 답한 경우에만 정답 확인합니다. 설명을 읽거나 다음으로 이동하는 행위는 숙달로 집계하지 않습니다.
- 빈 입력/잘못된 ID: 외부 API를 호출하지 않고 안내합니다.
- 키 미설정/비활성: 연결 준비 안내. 가짜 AI 답변으로 대체하지 않습니다.
- API 429: 이용 한도 안내. 4xx/5xx/형식 오류: 연결 또는 재시도 안내.
- 지연/취소: 타임아웃 또는 사용자 멈추기 처리. 입력 초안·현재 문항·기존 대화를 보존합니다.
- 실패 요청은 대화에 저장하거나 진도를 변경하지 않습니다. 성공한 응답만 한 번 저장합니다.

## 데이터·확장 구조

표시·제공하는 과정은 정보처리산업기사 실기 하나입니다. 문항을 데이터 파일로 분리하고 서버의 과정 레지스트리와 제공자 어댑터를 분리하여 향후 다른 과정·다른 AI를 추가할 수 있습니다. 미구현 과정이나 다른 자격증을 현재 제공한다고 표시하지 않습니다.

기출 원문·출판사 PDF·원본 앱 개인정보는 사용하지 않습니다. 진행 상태와 대화는 새 서비스의 브라우저 저장소에만 저장합니다. AI 질문을 보낼 때 선택한 제공자에게 현재 문항과 대화를 전달하며, 다른 질문의 기록이나 원본 자료실을 전송하지 않습니다.
