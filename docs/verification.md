## 자동 검증

`npm test`: JavaScript 6개 + Python 6개, 총 **12개 통과**.

- 출력 답의 내부 공백·줄바꿈·대소문자 보존, 용어의 등록 동의어 비교.
- 기본 Gemini 요청과 클라이언트가 정답을 전송하지 않는 구조.
- 빈 입력·알 수 없는 문항·제공자·잘못된 역할을 외부 호출 전에 거부.
- 서버의 원본 창작 문항으로 정답을 찾아 사용.
- 외부 호출 비활성/키 미설정 시 오류. 가짜 AI 답변 미사용.
- Gemini/OpenAI 어댑터의 실제 요청 규격과 응답 추출. 외부 네트워크는 모의 응답으로 대체하여 검증.
- 429, 서버 타임아웃, 잘못된 응답 형식 안내.
- 프론트 요청 취소와 응답 타임아웃.

데이터 검증: ID 중복 없음, 391개 창작 문항, 89개 수업, `refs/sources/source_paths/actual` 미포함.

## 브라우저 검증

로컬 Python 서버를 실행하고 Codex 브라우저로 확인했다.

- 5개 메뉴 이동, 질문·수업 선택, 단답 연습의 무작위 12문제 출제.
- 빈 답 안내, 실제 정답 비교와 해설, 오답 복습 등록.
- 새로고침 후 입력 초안·진도·복습 기록 복원.
- 프론트의 실제 `POST /api/chat`와 서버의 503 연결 준비 안내, 실패 시 초안 보존.
- 기록 초기화의 2단계 확인. 이 작업에서 입력한 검증용 기록만 정리했다.
- 1440×1000 데스크톱과 390×844 모바일에서 확인. 문서 가로 넘침 없음.
- 브라우저 JavaScript 오류 로그 없음. 로컬 `.env` 경로는 404로 차단됨.
