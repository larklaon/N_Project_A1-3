# AI 코딩 도구 사용 기록

도구: Codex. 작업일: 2026-10-12 (Asia/Seoul).

아래 인용은 이 작업의 실제 사용자·Codex 대화에서 발췌했습니다. 작업 설명은 별도 요약이며, 전체 대화의 원본을 대체하는 재구성 대화가 아닙니다. 키·토큰·개인 학습 기록은 포함하지 않습니다.

## 실제 대화 발췌

사용자:
> 당연히 그 폴더는 내가 쓰는거니까 건드리면 안되고, 필요한 것만 복사해와.

사용자:
> 아니 진짜 목업으로 하라는 이야기가 아니라, 진짜 정보가 안들어가도 된다는 말이었어 나는...

Codex:
> 내가 ‘목업’을 가짜 응답으로 동작하는 화면이라는 뜻으로 잘못 이해했어. 네 뜻은 **실제 기능은 구현하되, 콘텐츠와 예시 데이터는 생성한 것으로 써도 된다**는 거였네.

사용자:
> 음 그렇게 구조를 나눠야 되면, 그냥 api로만 동작되게 해줘.

사용자:
> 기본은 제미니로 둬줘!!

Codex:
> 기본 제공자를 **Gemini**로 바꿀게. OpenAI는 추가 선택지로 두고, 키와 모델 설정은 Python 백엔드의 환경 변수에서 관리할게.

## 실제 구현 작업 요약

1. 원본의 코드·문서·자료 구성을 읽고 과제 조건과 대조했다.
2. 원본에 대한 읽기 전용 해시 기준을 만들고, 창작 문항 JSON에서 허용 필드만 새 프로젝트로 추출했다.
3. 바닐라 화면과 별도 Python API를 작성하고 과제용 README·기획서를 작성했다.
4. Gemini 기본·OpenAI 추가 어댑터를 구현하고 공식 문서의 요청/구조화 응답 규격을 확인했다.
5. 단답 채점·오답 복습·진도/초안 복원과 두 화면 크기를 실제 브라우저에서 확인했다.
6. API 오류·미설정·타임아웃·형식 검증을 자동 테스트로 확인했다.
7. 사용자가 설정한 Gemini 키로 실제 요청했다. MIME enum 규격 오류를 수정한 뒤 정답·오답·힌트·이어지는 대화를 확인했다.
8. 코드를 GitHub에 푸시하고, 사용자 승인으로 Vercel GitHub 앱에 과제 저장소 한 개만 연결했다. 사용자가 GitHub 본인 확인을 완료했다.
9. Gemini 환경 변수를 Vercel에 등록하고 배포했다. 공개 URL에서 로그인 없이 메뉴·모바일·실제 AI 응답·단답·복습·저장을 검증하고 증빙을 저장했다.
