1. 원본의 코드·문서·자료 구성을 읽고 과제 조건과 대조했다.
2. 원본에 대한 읽기 전용 해시 기준을 만들고, 창작 문항 JSON에서 허용 필드만 새 프로젝트로 추출했다.
3. 바닐라 화면과 별도 Python API를 작성하고 과제용 README·기획서를 작성했다.
4. Gemini 기본·OpenAI 추가 어댑터를 구현하고 공식 문서의 요청/구조화 응답 규격을 확인했다.
